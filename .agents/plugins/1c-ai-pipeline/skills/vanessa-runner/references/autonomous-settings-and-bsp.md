# Автономная настройка Vanessa Automation, старт БСП и служебные обработки

## Ключи `vanessasettings` (JSON) для безоператорного прогона

При явной передаче `vanessasettings` сформируй JSON-конфигурацию с реальными путями текущего окружения:

- Базовое выполнение:
  - `КаталогФич` — путь к целевому `.feature`-файлу или каталогу сценариев;
  - `КаталогиБиблиотек` — массив существующих каталогов библиотек шагов;
  - `ВыполнитьСценарии: true`;
  - `ЗавершитьРаботуСистемы: true`;
  - `ОстановкаПриВозникновенииОшибки: false`.
- Отчётность (всегда указывай новый отдельный каталог результатов на каждый прогон):
  - Allure: `ДелатьОтчетВФорматеАллюр: true`, `КаталогOutputAllureБазовый`, `СоздаватьПодкаталогВКаталогеAllureДляЭтойСборки: false` (при необходимости итоговый HTML собирается штатным генератором Allure из JSON как отдельный артефакт на диске);
  - JUnit: `ДелатьОтчетВФорматеjUnit: true`, `КаталогOutputjUnit`.
- Режим без UI / без установленной компоненты `VanessaExt` (серверная или дымовая диагностика без снятия скриншотов средствами 1С):
  - `ИспользоватьКомпонентуVanessaExt: false`;
  - `ИспользоватьРедакторVanessaEditor: false`;
  - `ДелатьСкриншотПриВозникновенииОшибки: false`.
- Приёмка интерфейса со скриншотами средствами Vanessa:
  - требуется полная поставка Vanessa Automation (официальный `Single` либо полный комплект библиотек и макетов рядом с EPF — обычная сборка одного XML в `.epf` без библиотек не является полной поставкой) и установленная компонента `VanessaExt` (`QuietInstallVanessaExt` / `QuietInstallVanessaExtAndClose` в толстом клиенте; это отдельная операция, не заменяющая настройку доверия к внешним обработкам).

## Особенности первого запуска базы на БСП

- Успешная загрузка `.cf` / `.cfe` ещё не означает готовность базы к парному запуску `TestManager` + `TestClient`: после развёртывания конфигурации на БСП сначала доведи до конца штатные обработчики начального заполнения и обновления версии ИБ.
- Для только что созданной учётной записи пользователя учитывай, что при первом входе БСП может зарегистрировать пользователя в справочнике, обновить кэш ролей и инициировать перезапуск тонкого клиента **без** ключа `/Execute` — такой служебный перезапуск не является выполненным BDD-прогоном. Заверши первичный вход пользователя отдельно и запускай `test_vanessa` уже под готовой учётной записью.

## Отсутствие служебной внешней обработки (EPF)

- Если операция Runner сообщает об отсутствии служебной `.epf`, повторный вызов той же команды бесполезен и не должен подменяться ручным кликом по окнам.
- Проверь наличие исходников обработки в каталоге поставки Runner, собери `.epf` штатным инструментом `epf_compile` установленной версией платформы в ожидаемый путь и затем повтори исходную операцию.
