# Явно выбранная выгрузка Конфигуратора

Вход: существующий Configuration.xml из XML выгрузки, не Configuration.mdo.
Запустить `python scripts/configuration_overview.py <Configuration.xml>`
из каталога навыка, используя установленный Python 3.12 или новее.

JSON содержит путь, SHA-256 прочитанных байтов, свойства, синонимы по языкам,
список объектов и счётчики по типам. В `platform` — поставщик, режимы
совместимости конфигурации и расширений, вариант встроенного языка, основной
режим запуска, режим управления блокировкой и режим совместимости интерфейса.
Они ограничивают, на какой API платформы и поведение может опираться
изменение. Отсутствующее свойство — `null`; значение по умолчанию не
подставляется. Скрипт читает один файл, пишет в stdout, при ошибке возвращает
ненулевой код и JSON диагностики в stderr.

Другие файлы, состояние EDT и база не исследованы. Связь выгрузки с текущей
версией проекта этим инструментом не устанавливается. Скрипт не валидатор
платформы и не средство определения прав или поддержки конфигурации.
