# Обзор конфигурации

Вход: точный проект, формат исходника и границы исследования.
Выбрать интерфейс по формату ДО исполнения: это разные источники фактов.

- Проект 1С:EDT: [нативный обзор через edt-mcp](edt.md).
  Исследовать текущую модель EDT; экспорт для этого не требуется.
- Явно выбранная выгрузка Конфигуратора: [обзор Configuration.xml](xml.md).
  Результат относится к прочитанному файлу, не к состоянию EDT или базы.

Не переключаться на другой источник после отказа. Не подменять текущую модель
исторической выгрузкой. Для сравнения требуется отдельное задание с обеими
идентичностями и подтверждённой связью версий.

Собрать идентичность, свойства, состав по типам и ограничения полноты.
Материалы проекта сохранять в журнале своей операции хоста.
Совпадение имён или счётчиков не доказывает совпадение версий либо корректность.
Не выводить право изменения или состояние поддержки из отсутствия данных.

Ошибка чтения, неоднозначный проект, неполный ответ или недоступный инструмент
фиксируются как отказ либо явно ограниченное наблюдение.
Навык описывает предметное исследование. Следующий этап, повтор и приёмка
определяются задачей и процессом разработки; инструменты принадлежат соответствующим MCP-серверам.
