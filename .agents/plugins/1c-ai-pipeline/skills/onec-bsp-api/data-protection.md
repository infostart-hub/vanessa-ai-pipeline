# Запрет редактирования, дополнительные свойства и даты запрета

Карта для подсистем ЗапретРедактированияРеквизитовОбъектов, Свойства и ДатыЗапретаИзменения. Имена и регионы подтверждены для БСП 3.1.11. Для целевого проекта сверяй модуль, сигнатуру и регион по модели EDT.

## Модули

| Модуль | Роль |
|---|---|
| ЗапретРедактированияРеквизитовОбъектов | Сервер: ЗаблокироватьРеквизиты, БлокируемыеРеквизитыОбъекта, НовыйБлокируемыйРеквизит |
| ЗапретРедактированияРеквизитовОбъектовКлиент | Клиент: РазрешитьРедактированиеРеквизитовОбъекта и состояние элементов |
| ЗапретРедактированияРеквизитовОбъектовПереопределяемый | Хуки регистрации объектов и состава реквизитов |
| УправлениеСвойствами / УправлениеСвойствамиКлиент | Дополнительные реквизиты и сведения в формах и коде |
| УправлениеСвойствамиПереопределяемый | Хуки наборов свойств |
| ДатыЗапретаИзменения | Проверка запрета изменения и загрузки |
| ДатыЗапретаИзмененияПереопределяемый | Хуки разделов и источников данных проверки |

Не существуют: ЗапретРедактированияРеквизитовОбъектовКлиентСервер, метод СнятьЗапрет (снятие запрета только через команду пользователя), УправлениеСвойствамиКлиентСервер, ПроверкаЗаполненияСлужебный. Устарели: УправлениеСвойствами.ПолучитьЗначенияСвойств, ПолучитьСписокСвойств, ПолучитьСписокЗначенийСвойств; ДатыЗапретаИзменения.ОбновитьРазделыДатЗапретаИзменения.

## Запрет редактирования реквизитов

- Объект регистрируется в ПриОпределенииОбъектовСЗаблокированнымиРеквизитами; список реквизитов возвращает функция модуля менеджера ПолучитьБлокируемыеРеквизитыОбъекта. Без регистрации блокировка не работает.
- Массив имён создают через Новый Массив и Добавить: аргументы конструктора массива задают размеры, а не элементы.
- В форме: ЗаблокироватьРеквизиты(ЭтаФорма) в ПриСозданииНаСервере для записанного объекта и после записи нового. БСП добавляет команду, но процедуру Подключаемый_РазрешитьРедактированиеРеквизитовОбъекта с вызовом клиентского API форма объявляет сама.
- Ручная установка ТолькоПросмотр теряет проверку прав и команду разблокировки.

## Дополнительные реквизиты и сведения

- Форма объекта вызывает УправлениеСвойствами.ПриСозданииНаСервере, ПриЧтенииНаСервере, ПередЗаписьюНаСервере; служебные реквизиты формы БСП создаёт сама.
- В ОбработкаПроверкиЗаполненияНаСервере формы первым вызывается УправлениеСвойствами.ОбработкаПроверкиЗаполнения, иначе обязательность доп. реквизитов не проверяется.
- В коде: ЗначениеСвойства, пакетный ЗначенияСвойств, СвойстваОбъекта, ЗаписатьСвойстваУОбъекта. Прямая запись в табличную часть ДополнительныеРеквизиты обходит контроль типов.
- Изменение управляющего реквизита — УправлениеСвойствамиКлиент.ОбновитьЗависимостиДополнительныхРеквизитов; оповещения — ОбрабатыватьОповещения.

## Даты запрета изменения

- В формах ДатыЗапретаИзменения.ОбъектПриЧтенииНаСервере(ЭтаФорма, ТекущийОбъект) переводит форму в просмотр для закрытого периода.
- Подписки БСП проверяют запись зарегистрированных объектов, но программная запись из регламентного задания, обработки или обмена требует явной проверки: ИзменениеЗапрещено(ДанныеИлиПолноеИмя, ИдентификаторДанных, ОписаниеОшибки, УзелПроверкиЗапретаЗагрузки) или НайденЗапретИзмененияДанных с данными из ШаблонДанныхДляПроверки.
- Для загрузки при обмене передают узел: это отдельная дата запрета загрузки.
- ОтключитьПроверкуДатЗапрета допустим только для обоснованного привилегированного кода, например обработчика обновления.
- Состав разделов задаёт хук ПриЗаполненииРазделовДатЗапретаИзменения; без него действует только общая дата.
