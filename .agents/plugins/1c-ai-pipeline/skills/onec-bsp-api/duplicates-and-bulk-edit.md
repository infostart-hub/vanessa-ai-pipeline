# Дубли, замена ссылок, групповое изменение и связанные документы

Карта для подсистем ПоискИУдалениеДублей, ГрупповоеИзменениеОбъектов и СтруктураПодчиненности. Имена и регионы подтверждены для БСП 3.1.11. Для целевого проекта сверяй модуль, сигнатуру и регион по модели EDT.

## Модули

| Модуль | Роль |
|---|---|
| ПоискИУдалениеДублей | Серверный API поиска дублей и нечёткого сравнения строк; часть методов служебные |
| ПоискИУдалениеДублейКлиент | Формы объединения, замены и мест использования |
| ПоискИУдалениеДублейПереопределяемый | Хуки состава объектов и прикладных правил |
| ГрупповоеИзменениеОбъектовКлиент | ИзменитьВыделенные |
| ГрупповоеИзменениеОбъектовПереопределяемый | Хуки состава объектов и редактируемых реквизитов |
| СтруктураПодчиненностиПереопределяемый | Только хуки отчёта «Связанные документы» |

Не существуют: модуль СтруктураПодчиненности без суффикса, модули Служебный/ВызовСервера/ПовтИсп у ПоискИУдалениеДублей и ГрупповоеИзменениеОбъектов. У структуры подчинённости нет программного API формирования отчёта.

## Дубли и замена

- Дубли элемента: ПоискИУдалениеДублей.НайтиДублиЭлемента(ОбластьПоиска, ЭталонныйОбъект, ДополнительныеПараметры) возвращает таблицу Ссылка, Код, Наименование, Родитель и учитывает прикладные правила ПриОпределенииПараметровПоискаДублей / ПриПоискеДублей. В результат входит сам эталон. Прямой запрос по равенству наименования эти правила не учитывает.
- Нечёткое сравнение строк: НайтиПохожиеСтроки с параметрами из ПараметрыПоискаПохожихСтрок, полученными один раз до цикла: каждый вызов без них заново подключает внешнюю компоненту.
- Стабильная замена ссылок: ОбщегоНазначения.ЗаменитьСсылки(ПарыЗамен, ПараметрыЗамены) с ОбщегоНазначения.ПараметрыЗаменыСсылок(): СпособУдаления, УчитыватьПрикладныеПравила, ВключатьБизнесЛогику. Возвращает таблицу ошибок; пары Ключ — дубль, Значение — оригинал.
- ПоискИУдалениеДублей.ЗаменитьСсылки и ПроверитьВозможностьЗаменыЭлементов служебные. Проверку прикладных правил включает УчитыватьПрикладныеПравила = Истина в стабильном вызове.
- ДополнитьДублиСвязаннымиПодчиненнымиОбъектами добавляет к парам связанные подчинённые объекты.
- Длительную замену запускай фоном через ДлительныеОперации (см. background-and-scheduled.md).
- Если пользователю нужно сообщить найденный дубль, верни его ссылку и реквизит, по которому он найден (например, код), из результата поиска; не формируй ответ по одному наименованию.

## Групповое изменение и связанные документы

- ГрупповоеИзменениеОбъектовКлиент.ИзменитьВыделенные(СписокЭлемент, СписокРеквизит) открывает обработку группового изменения. При подключаемых командах кнопки добавляются автоматически; ручное добавление их дублирует.
- Запрет массового изменения реквизитов: функции модуля менеджера РеквизитыНеРедактируемыеВГрупповойОбработке / РеквизитыРедактируемыеВГрупповойОбработке и регистрация в ПриОпределенииОбъектовСРедактируемымиРеквизитами. Нередактируемые имеют приоритет.
- Связанные документы: хуки ПриОпределенииНастроек, ПриПолученииПредставления, ПередВыводомСвязанногоОбъекта. Отказ = Истина скрывает объект, но не его подчинённые.
