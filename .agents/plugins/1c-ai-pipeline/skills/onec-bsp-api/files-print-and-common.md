# Присоединённые файлы, печать, общие модули и безопасное хранилище БСП

Используй эту карту вместе с основным алгоритмом `SKILL.md` (сверяя точные имена и сигнатуры по установленной версии БСП через `edt-mcp`), когда задача затрагивает работу с файлами, версионирование, базовые утилиты `ОбщегоНазначения`, хранение секретов или подключение печати и внешних команд.

## Присоединённые файлы и хранение двоичных данных

- Различай общий справочник `Файлы` (общие папки файлов) и специализированный справочник присоединённых файлов конкретного владельца (например, `<ИмяОбъекта>ПрисоединенныеФайлы`, определяемый тип `ВладелецПрисоединенныхФайлов`).
- Основной серверный API сосредоточен в `РаботаСФайлами` / `РаботаСФайламиВызовСервера`, клиентский — в `РаботаСФайламиКлиент`. Не записывай `ДвоичныеДанные` напрямую в реквизит типа `ХранилищеЗначения` карточки документа или справочника: в конфигурациях на БСП файлы размещаются через подсистему работы с файлами с учётом настройки хранения (в информационной базе или в томах на диске) и ограничений размера/расширений.
- Передача файла с клиента на сервер выполняется через временное хранилище (`НачатьПомещениеФайлаНаСервер` / `ПоместитьФайлНаСерверАсинх`), а регистрация присоединённого файла — штатным серверным методом подсистемы, который заполняет размер, расширение, автора, дату изменения и версию файла.

## Базовые утилиты `ОбщегоНазначения` и чтение реквизитов без лишних запросов

- Для чтения одного реквизита ссылки на сервере используй `ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Ссылка, "ИмяРеквизита")`, для нескольких реквизитов одной ссылки — `ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Ссылка, "Реквизит1, Реквизит2")`, а для **массива ссылок** (например, из табличной части) — пакетный вариант `ОбщегоНазначения.ЗначенияРеквизитовОбъектов(МассивСсылок, ...)`, чтобы избежать `N+1` обращений к базе и разыменования через точку.
- Для привязки сообщений об ошибках к элементам формы и строкам табличной части используй `ОбщегоНазначенияКлиентСервер.СообщитьПользователю(ТекстСообщения, КлючДанных, Поле, ПутьКДанным, Отказ)`: для табличной части формируй индекс строки штатным помощником (`СтрокаТабличнойЧастиДляСообщения` / формат `"Товары[0].Количество"` с 0-индексацией), чтобы курсор вставал точно в ошибочную ячейку.
- Для разбора и форматирования строк с подстановками параметров по стандарту БСП используй `СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку` (или платформенный `СтрШаблон` с локализованным шаблоном `НСтр`).

## Хранение паролей, токенов и ключей API

- Никогда не храни пароли учётных записей, Bearer-токены и секретные ключи внешних сервисов в открытых строковых константах, реквизитах справочников или коде модулей.
- Используй платформенное и библиотечное безопасное хранилище через публичные методы `ОбщегоНазначения` (`ЗаписатьДанныеВБезопасноеХранилище`, `ПрочитатьДанныеИзБезопасногоХранилища` — сверь точные имена и параметры в текущей версии БСП проекта) с привязкой к объекту настройки интеграции. Чтение из безопасного хранилища выполняй только на сервере непосредственно перед установкой соединения, не возвращая секрет в реквизиты управляемой формы на клиент.

## Навигация по смежным подсистемам БСП (печать и внешние обработки)

- При подключении макетов и команд к подсистеме **`УправлениеПечатью`** (`ДобавитьКомандыПечати`, `Печать`, таблица `ПараметрыВывода`, комплекты печати) используй профильный навык `onec-print-forms-and-mxl`.
- При оформлении экспортной функции **`СведенияОВнешнейОбработке()`** и регистрации `.epf` / `.erf` в подсистеме `ДополнительныеОтчетыИОбработки` используй профильный навык `onec-external-processors-and-delivery`.
